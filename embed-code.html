埋め込みコード

GitHub Pagesを有効化したあと、YOUR_GITHUB_USERとYOUR_REPO_NAMEを実際の値に置き換えてください。

画像だけを埋め込む場合

<figure style="margin:0; max-width:960px;">
  <img
    src="https://YOUR_GITHUB_USER.github.io/YOUR_REPO_NAME/environmental-immunotoxicology-research.jpg"
    alt="カビ毒や環境汚染物質が免疫細胞を介して皮膚炎や気道炎症に関わる流れを示す研究イメージ"
    style="width:100%; height:auto; border-radius:8px;"
  >
  <figcaption style="font-size:0.9em; color:#5b676b; margin-top:0.6em;">
    カビ毒等環境汚染物質と免疫の関係を示す研究イメージ
  </figcaption>
</figure>

ページとして埋め込む場合

<iframe
  src="https://YOUR_GITHUB_USER.github.io/YOUR_REPO_NAME/"
  title="知られざる毒の世界：研究イメージ"
  style="width:100%; max-width:1100px; height:760px; border:0; border-radius:8px;"
  loading="lazy"
></iframe>
